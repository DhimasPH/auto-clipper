Auto Clipper — UI/UX Revamp

Static prototype · every screen and every state, no backend attached.

How to read this prototype

Nothing is wired to the Python backend. Screens that have more than one state carry a Prototype state switcher in the bottom-right corner — use it to jump between empty, running, error and completed views instead of waiting for a timer. Actions with no static destination will tell you so rather than silently doing nothing.

What changed vs. the current build

Status vocabulary

The prototype proposes one shared vocabulary. Two changes matter: CROPPING is renamed to RENDERING (it also burns subtitles and draws the canvas, so the old name under-described it), and ANALYZING is new — today the LLM step has no status of its own, so the UI sits on TRANSCRIBING while it runs.

Brand assets, accent colour and token names are carried over unchanged from src/index.css and tailwind.config.js.
