# Auto Clipper - AI Agent Guidelines & Context Hub

Panduan arsitektur, standar kode, dan aturan kerja untuk AI Agent pada repositori `auto-clipper`.

> **Ada pekerjaan yang sedang berjalan.** Sebelum mengerjakan apa pun, baca `tasks/HANDOFF-AI.md`: posisi terakhir, keputusan yang sudah diambil, cara kerja per task, dan lingkungan mesin ini.

---

## 1. Arsitektur Proyek & Tech Stack

- **Frontend (satu kode, `src/`)**: React 19 + TypeScript 6 + Vite 8 + Tailwind CSS 3 + Lucide React + React Router (`HashRouter`), uji Vitest, lint oxlint. Berjalan di tiga platform lewat `src/platform/` (ADR-013): **desktop** (dibungkus Tauri v2), **web lokal** (disajikan backend `--web`, paket "Auto Clipper Web"), dan **cloud** (Vercel, `npm run build:cloud` dengan `VITE_TARGET=cloud`, backend di Colab). Folder `web/` sudah dihapus. Antarmuka SP2 (ADR-014): tiga menu (Buat klip `/`, Riwayat `/riwayat`, Pengaturan `/pengaturan`), alur Buat klip empat langkah, desain HP dulu, AI manual sebagai jalur bawaan.
- **Backend Core (Sidecar)**: Python 3.11+ berjalan sebagai server lokal **FastAPI** yang dibungkus menjadi single executable dengan PyInstaller (`backend-x86_64-pc-windows-msvc.exe` di folder `bin/`).
- **Cloud Backend Support**: Backend Python mendukung eksekusi di cloud GPU (seperti Google Colab) menggunakan *Ngrok* atau *Cloudflare tunnel*. Frontend Web berkomunikasi menggunakan `AUTO_CLIPPER_WEB_TOKEN`. Di Colab, pustaka (`AUTO_CLIPPER_WORKSPACE`) ada di Google Drive dan disk kerja (`AUTO_CLIPPER_WORK_DIR=/content/work`) di disk lokal (ADR-012).
- **Database**: SQLite (`history.db`) via `backend/db.py` untuk mengelola riwayat job, metadata klip, dan status pemrosesan. Dengan `AUTO_CLIPPER_WORK_DIR` aktif, database dibuka di work dir dan di-snapshot ke `<pustaka>/history.db` (ADR-012).
- **AI & Processing Pipeline**:
  - **Speech-to-Text**: `faster-whisper` (didukung model: `small`, `medium`, `large-v3`) + Silero VAD filter (`min_silence_duration_ms=500`).
  - **Highlight Extraction & Social Kit**: **AI Provider Registry** (Mendukung provider dinamis seperti OpenAI, Gemini, dll) dengan parser JSON tangguh (`clean_json_response`).
  - **Face Detection & Tracking**: OpenCV Haar Cascade + Exponential Moving Average (EMA, alpha ~0.25) + ekspresi interpolasi FFmpeg dinamis.
  - **Subtitles**: Engine ASS single-word pop karaoke non-overlapping (`words_to_karaoke_ass`) & sentence reconstruction (`words_to_standard_ass`) dengan tipografi kustom (ADR-009).
  - **Video Rendering & Cropping**: FFmpeg via subproses Python (menggunakan Hardware Acceleration `h264_nvenc` dengan mekanisme fallback otomatis ke `libx264`).
  - **Downloader**: `yt-dlp` dengan urutan client `default → web_embedded → android_vr` (masing-masing sekali), `cookies.txt` unggahan pengguna (`backend/cookies.py`), dan Deno + komponen EJS (`remote_components=['ejs:github']`) bila `deno` ada di `PATH`. Format default H.264 ≤1080p. Semua kegagalan dipetakan ke `AppError` lewat `classify_download_error` (ADR-012).
  - **Error, Antrean & Preflight**: `AppError` berkode (`backend/errors.py`) di `job["error_info"]`; satu slot job berat (`backend/job_queue.py`); pengecekan awal `GET /api/preflight` (`backend/preflight.py`); laporan waktu per tahap di `metadata["timings"]` dan tahap yang sedang berjalan di `current` status job (`backend/stage_timer.py`, ADR-014).

## 2. Aturan Baku Pengembangan (Rules & Invariants)

### A. Handshake Sidecar & Larangan Print Stdout (Kritis)
1. Backend berkomunikasi dengan frontend melalui REST API lokal dengan port dinamis dan token autentikasi (`API_SECRET_TOKEN`).
2. **JANGAN PERNAH** menuliskan `print()` sembarangan ke `stdout` di modul backend manapun. Handshake Tauri bergantung pada format stdout ketat dari `backend/main.py` (`PORT:<port>` dan `TOKEN:<token>`). Output liar di stdout akan menggagalkan inisialisasi aplikasi. Pengecualian: mode web lokal (`--web`) tidak memakai handshake; `backend/web_mode.launch` menulis teks konsol ke stream yang diberikan blok `__main__` (ADR-013).
3. **Sidecar Auto-Recovery & Health Polling**: Frontend memantau status backend melalui endpoint `POST /heartbeat` dan `GET /health`. Jika koneksi terputus, frontend dapat me-restart sidecar (`resetAndRespawnBackend`). Interceptor HTTP dan fetch di sisi frontend harus diatur ulang (re-wire) dengan token yang baru saat sidecar di-restart.
4. **Cross-Platform CORS Invariant (ADR-011)**: Backend FastAPI **WAJIB** mengizinkan origin dari semua platform desktop webview (Windows WebView2: `http://tauri.localhost` / `https://tauri.localhost`, macOS WKWebView: `tauri://localhost` / `tauri://*`, dan local dev server) menggunakan format regex komprehensif: `r"https?://([a-zA-Z0-9_.-]+\.)?localhost(:\d+)?|https?://127\.0\.0\.1(:\d+)?|tauri://.*|app://.*"`. Dilarang menggunakan regex sempit yang mengecualikan subdomain localhost. `CORSMiddleware` didaftarkan **setelah** middleware token (`verify_token`) agar menjadi lapisan terluar: jawaban 401 tetap membawa header CORS untuk origin yang diizinkan, sehingga aplikasi cloud bisa membedakan "kode akses salah" dari "server offline".

### B. Standarisasi Error Logging & Exception (ADR-006)
1. Semua error, peringatan, dan exception di backend **HARUS** dicatat menggunakan `log_error(err, context="...")` dari `backend.logger`.
2. Log disimpan ke file `backend_error.log` secara fail-safe dengan encoding UTF-8.
3. Error di sisi frontend diteruskan ke backend melalui endpoint `POST /log-error`.
4. Endpoint FastAPI dilindungi oleh `@app.exception_handler(Exception)` dan `sys.excepthook` untuk mencegah unhandled crash.

### C. Offline-First & Whisper Model Management (ADR-005)
1. Model Whisper default adalah `small`. Model yang lebih besar (`medium`, `large-v3`) diunduh secara eksplisit melalui endpoint `POST /api/settings/whisper-models/download`.
2. Saat eksekusi job transkripsi, parameter `local_files_only=True` selalu diaktifkan untuk model non-default agar tidak pernah mencoba mengunduh diam-diam saat offline atau koneksi tidak stabil.
3. Selalu sertakan `vad_filter=True` untuk memangkas jeda hening dan mencegah halusinasi teks berulang.
4. **AI Provider Registry & Dynamic Models**: Sistem **tidak boleh** melakukan hardcode pada model LLM. Selalu gunakan sistem *AI Provider Registry* yang mengambil konfigurasi model secara dinamis dari frontend/backend settings.

### D. Video Cropping, Canvas Styling & Karaoke Subtitle Invariants (ADR-003, ADR-008, ADR-009, ADR-015)
1. **Face Tracking Crop**: Pemotongan video portrait (9:16) standard harus menggunakan `sample_face_trajectory` + `smooth_trajectory` + `build_dynamic_crop_filter` agar kamera mengikuti pergerakan wajah pembicara secara halus. Mode **Teliti** (`engine="mediapipe"`) memakai `_FaceLandmarkerAdapter` (MediaPipe Tasks 1.0+ dengan `face_landmarker.task` dari add-on atau `<repo>/bin/mediapipe_colab`) dan kompatibel dengan `solutions.face_mesh.FaceMesh`; bila add-on tidak ada atau gagal, wajib jatuh aman ke `haar`, mencatat `log_app` + `log_error`, mengirim status live `haar_fallback`, dan menyinkronkan `tracking_fallback_reason` lewat `jobs._sync_stage_metadata()`.
2. **Canvas Background Styling & Zoom (ADR-008)**: Saat opsi Canvas Styling aktif pada video landscape (16:9), pipeline merender video di atas kanvas 9:16 dengan opsi latar (`blur` [light, medium, heavy], `color` solid, atau `image` kustom) serta pembesaran `enlarge_scale` (1.0x - 2.0x) secara proporsional tanpa memotong sisi video.
3. **Adaptive Subtitle Margin**: Pada mode kanvas, posisi vertikal subtitle ASS disesuaikan secara otomatis (`MarginV` dinaikkan) agar teks berada tepat di area kosong bawah video tanpa menutupi visual utama.
4. **Subtitle Zero-Overlap Invariant (ADR-009)**: Subtitle karaoke wajib menggaransi `end_i <= start_{i+1}` pada flat-word list sehingga kata aktif tampil tunggal (single-word pop) tanpa tumpang tindih waktu antar kata. Format warna primer ASS adalah `&H00BBGGRR` (8-digit hex) dan font weight mendukung `bold` (`Bold=-1`) serta `normal` (`Bold=0`).
5. **Universal Word-Level Transcription & Mode Dispatch**: Whisper wajib selalu mengekstrak word timestamps (`words.json`). Mode subtitle (`standard` vs `karaoke`) dikontrol oleh `subtitle_config.style`, bukan oleh ekstensi file input.
6. **Pipeline Metadata Invariant**: Properti `canvas_config` dan `subtitle_config` **HARUS** dipropagasikan dan dipertahankan di seluruh alur pembuatan job (`create_job`, `create_manual_job`, `create_rerender_job`, `create_rerun_ai_job`) serta alur resume (`create_resume_job`, `resume_manual_job`).
7. Pipeline wajib mendeteksi layout video asli (Landscape/Portrait) secara otomatis sebelum pemrosesan klip.
8. **NVENC Fallback**: Semua *command* FFmpeg untuk rendering video wajib mengimplementasikan percobaan hardware encoding dengan `h264_nvenc`. Jika terjadi error (misalnya karena driver tidak tersedia atau memori GPU penuh), command tersebut harus ditangkap dan fallback secara aman ke CPU encoding (`libx264`). Fallback tidak boleh diam-diam: encoder yang dipakai dicatat di `metadata["timings"]` (`encoder`) dan preflight melaporkan `gpu_render` (ADR-012). Notebook Colab memakai FFmpeg dari apt, jadi NVENC di Colab tidak dijamin.
9. **FFmpeg Path Discovery Hierarchy**: Resolusi path binary FFmpeg wajib memeriksa hirarki `bin_dir`, `bin_dir.parent`, `os.path.dirname(bin_dir)`, dan fallback `PATH` sistem agar konsisten di environment dev, PyInstaller onefile, maupun macOS app bundle.
10. **Custom Subtitle Persistence Invariant**: Setiap modifikasi subtitle kustom per-klip (revisi manual) **WAJIB** disimpan jalurnya (`custom_subtitle_path`) ke dalam objek `result_clips` pada *history database*. *Endpoint* `api_get_clip_words` dan proses batch `_run_rerender_job` **WAJIB** memprioritaskan membaca `clip.get("custom_subtitle_path")` dibandingkan `metadata.get("subtitle_path")`. Hal ini menjamin revisi kata-per-kata yang dilakukan pengguna tidak tertimpa oleh transkripsi *full-video* asli saat dilakukan "Rerender All Clips".
11. **Gaming Layout Auto-Detection & Split-Screen**: Pipeline video secara otomatis dapat mendeteksi layout *gaming* dan mendukung *vertical split-screen cropping* (memotong layar video menjadi atas dan bawah) yang disesuaikan dengan posisi subtitle.
12. **Watermark Support**: Sistem mendukung penambahan *watermark* pada video hasil render akhir.

### E. Multi-Stage Resume, Job Workspaces, & Mode (AI vs Manual)
1. Fitur retry/resume di `backend/jobs.py` tidak boleh mengunduh ulang video jika file lokal sudah tersedia.
2. Jika transkripsi atau highlight sudah ada, gunakan kembali data yang tersimpan di `history.db` tanpa memanggil ulang Whisper atau LLM secara sia-sia.
3. **Project Workspace Isolation**: Semua artefak hasil pemrosesan (video mentah, file `.ass`, dan potongan `.mp4`) **HARUS** di-route dan disimpan di dalam sub-direktori *project workspace* yang terisolasi untuk masing-masing job/project (bukan di root atau shared flat directory).
4. Backend dan frontend mendukung mode alur kerja **AI-driven** maupun **Manual Editor**; metadata klip tidak selalu dihasilkan otomatis oleh LLM.
5. **Manual Downloader Enhancements**: Fitur downloader mendukung pengunduhan *full video* (tanpa memotong klip / *empty clips allowed*) dan pengguna dapat memilih kualitas resolusi video saat mengunduh.
6. **Penghapusan Smart Editor**: Fitur eksperimental *Smart Editor* telah **dihapus secara permanen**. Semua alur penyuntingan dan pemotongan (cropping) kini sepenuhnya mengandalkan pengaturan UI standar, *Gaming Mode*, dan modul *Canvas Config*.
7. ~~**Web UI Draft State Invariant**~~: dihapus bersama `web/` (SP1, ADR-013).
8. **Work Dir vs Pustaka (ADR-012)**: `get_project_workspace()` mengembalikan `project_dir` (tempat kerja, di work dir bila `AUTO_CLIPPER_WORK_DIR` aktif) dan `library_dir` (pustaka). Semua file antara ditulis ke `project_dir`. Hasil yang harus bertahan dipindahkan ke pustaka **hanya** lewat `workspace.publish()` / `copy_atomic()` (nama `.part` lalu `os.replace`), setelah setiap klip dan di akhir job. Tanpa work dir, kedua path sama dan perilaku desktop tidak berubah.
9. **Riwayat Tidak Pernah Menunjuk ke Work Dir**: Path di `result_clips` (`path`, `custom_subtitle_path`) dan `metadata.subtitle_path` yang disimpan ke `history.db` **WAJIB** menunjuk ke pustaka setelah publish. Video sumber tidak dipublikasikan; alur yang membutuhkannya (Resume, rerender, AI Koreksi, resume-manual) **WAJIB** memanggil `jobs._restore_source_video()` (unduh ulang job URL, salin ulang file `local:`, atau `UPLOAD_MISSING`).
10. **Semua Thread Job Lewat Antrean**: Setiap job di `backend/jobs.py` **WAJIB** dimulai lewat `_start_job()` → `job_queue.submit()`, tidak pernah dengan `threading.Thread` langsung. Slot dikontrol `AUTO_CLIPPER_MAX_HEAVY_JOBS` (default 1). Resume untuk proyek yang masih antre/berjalan ditolak. (Pengecualian lama yang belum dipindah: `backend/metadata.py`.)
11. **Snapshot `history.db`**: Hanya `backend/db.py` yang tahu soal snapshot. Status akhir job ditulis ke snapshot sebelum `save_history` kembali; perubahan lain dibatasi sekali per 5 detik. Jangan menulis langsung ke `<pustaka>/history.db` saat work dir aktif.
12. **Error Terstruktur**: Kegagalan yang bisa ditindaklanjuti pengguna **WAJIB** dilempar/dicatat sebagai `AppError(code, technical=...)` dari `backend/errors.py`. Kode baru wajib punya `title`/`message` (id) dan `title_en`/`message_en` (en) berbahasa awam (apa, kenapa, harus apa) dan aksi dari `_ACTIONS`. Teks mentah hanya di `technical`. Frontend hanya merender `error_info` lewat `ErrorCard`, tidak menulis teks error sendiri. (Pengecualian sempit untuk kegagalan yang tidak bisa dilaporkan backend: lihat F.7 dan ADR-013.)
13. **Cookies Tidak Pernah Bocor**: Isi `cookies.txt` tidak boleh masuk log, pesan error, atau respons API. yt-dlp hanya menerima salinan kerja dari `cookies.ytdlp_cookiefile()`, tidak pernah file yang tersimpan.
14. **Path dari Request Tidak Boleh Menyentuh File Privat (`T0.19`, `T1.y`, ADR-015)**: Setiap endpoint yang membaca, menyajikan, menyalin, atau menulis file berdasarkan path dari request (`/video`, `/save_file` sumber dan tujuan, `/api/thumbnails`, `/api/extract-metadata`) **WAJIB** memanggil `path_guard.is_protected()` sebelum memeriksa keberadaan file, dan menjawab `path_guard.denied()` (403, `Access denied`). Hal yang sama berlaku untuk `canvas_config.background_image_path` di semua endpoint pembuat job (`POST /jobs`, `/jobs/manual`, `/jobs/{id}/rerender`, `/jobs/{id}/rerun_ai`, `/jobs/{id}/clips/{n}/rerender`) lewat `_canvas_image_refused()` di `backend/main.py`, dan untuk tujuan tulis `POST /upload-image` (ADR-014); endpoint baru yang menerima `canvas_config` wajib memanggilnya. Yang dilindungi: folder `cookies/` dan folder salinan kerja cookies, semua file `history.db*` (termasuk `-wal`/`-shm`/`-journal`, snapshot, `.part`), log `backend_*.log`, kunci video `video_signing.key`, file instance web lokal `web_instance.json`, dan file port web lokal `web_port.json`, serta bentuk path perangkat NT non-drive (`\?\GLOBALROOT\...`, `\?\Volume{...}\`, `\??\...`) dan NTFS alternate data stream (`:` di luar huruf drive). Nama file unggahan selalu lewat `path_guard.safe_upload_name()`.
   - **`output_dir` khusus Desktop (`T1.y`, ADR-015)**: Pada mode Cloud dan Web Lokal (`web_ui.is_web_mode()`), `output_dir` dari request atau histori lama **wajib diabaikan/dikosongkan**. Pada Desktop, `output_dir` hanya boleh path absolut lokal (huruf drive lokal di Windows / absolut POSIX; path UNC/perangkat ditolak 403) yang disimpan dalam bentuk `realpath`, dan baik `output_dir` maupun `<output_dir>/<safe_title>` wajib lolos `_resolve_safe_output_dir()` dan `jobs.refuse_protected_project_dir()` (tidak berada di dalam `addons/`/`temp_downloads/`, tidak menampung folder kerja aplikasi `projects`/`addons`/`temp_downloads`/`cookies`). `sanitize_title()` menolak nama titik-saja (`..`) dan memangkas titik/spasi akhir.
   - **Penolakan teks-dulu & folder proyek yang diizinkan**: `/video`, `/save_file`, dan route statis tanpa token `/assets/` (`web_ui._serve`) **WAJIB** menolak path teks UNC (`\\`, `//`) dan prefiks perangkat NT sebelum menyentuh filesystem (`realpath` / `os.path.join`) agar tidak memicu SMB. `/video` dan `/save_file` memakai `path_guard.is_within()` terhadap folder data/kerja yang sah serta `workspace.allowed_project_output_dirs(active_jobs)` (per folder proyek `<output_dir>/<safe_title>`, kosong di Cloud).
15. **Kunci API Tidak Pernah Disimpan (T0.18)**: `api_key` dan `pexels_api_key` (`workspace.SECRET_KEYS`) hanya ada di job yang sedang berjalan, tidak pernah di metadata `history.db` (yang disalin ke Google Drive) maupun `metadata.json`. `db.save_history` membuangnya; `init_db` dan sinkronisasi snapshot membersihkan baris lama. Resume dan resume-manual memakai kunci yang dikirim aplikasi di request. Provider yang butuh kunci tetapi tidak menerimanya ditolak dengan `AI_KEY_MISSING`; B-roll tanpa kunci Pexels dilewati dengan catatan di log.
16. **Drive Colab Belum Ter-mount (T0.17)**: Bila mode cloud aktif dan pustaka ada di bawah `/content/drive` yang belum menjadi titik mount, backend **tidak boleh** membuat apa pun di bawah `/content/drive` (Colab menolak `drive.mount` ke folder yang sudah berisi file). `get_app_data_dir()`, `get_work_dir()`, `copy_atomic` dan snapshot memanggil `drive_mount.refuse_unmounted()` (melempar `AppError("DRIVE_NOT_MOUNTED")`), preflight `drive` bernilai `block`, dan log serta `history.db` ditulis ke `drive_mount.local_dir()` (work dir). Folder baru yang mungkin berada di pustaka wajib lewat jalur yang sama.
17. **Alamat Video Bertanda Tangan (ADR-013)**: `GET /video` **WAJIB** menolak (403) `sig` yang hilang atau salah di semua platform, sesudah `path_guard` dan sebelum pemeriksaan folder. `sig` hanya dibuat `backend/video_sign.py` (`HMAC_SHA256(video_signing.key, path kanonik)`, tanpa kedaluwarsa). Link ditambahkan saat data klip dibaca (`with_video_urls` di `GET /jobs/{id}` dan `GET /history`) atau lewat `POST /video-url`, dan **tidak pernah** disimpan di `history.db`. Pengecualian token di `verify_token` persis `path == "/video"`. Frontend tidak boleh menyusun URL `/video` sendiri (dijaga `src/lib/videoUrl.test.ts`).
18. **Mode Web Lokal (ADR-013)**: `backend --web` hanya bind ke `127.0.0.1`; port peluncuran sebelumnya dipakai ulang bila masih kosong (`web_port.json`, 0600, supaya pengaturan dan API key di browser yang tersimpan per alamat tidak hilang), selain itu port acak; token acak per peluncuran; satu instance per komputer (`web_instance.json`). Di mode ini hanya `/`, `/assets/*`, file gambar root UI, dan `/health` yang tanpa token (`web_ui.is_public_path`); `/video` memakai `sig`; yang lain, termasuk `/heartbeat`, wajib token. Tidak ada watchdog heartbeat di mode ini. Port dianggap terpakai bila `connect(("127.0.0.1", port))` berhasil, baru setelah itu diuji dengan bind (`port_is_free`).
19. **Tahap Berjalan di Status Job (ADR-014)**: `GET /jobs/{id}` membawa `current` = `{stage, started_at, elapsed_seconds, device?, clip?, clips_total?, percent?}` dari `stage_timer.current_stage(job["_live"])`, dibangun saat dibaca. Tumpukan tahap hidup diisi `stage()` di dalam `collect_timings(timings, live)` dan selalu diganti dengan list baru (dibaca thread lain). Fakta yang hanya untuk status (`percent` unduhan, `clips_total`) lewat `stage_timer.report()`, **tidak pernah** masuk `timings`, `metadata`, atau `history.db`. Tahap berat baru wajib dibungkus `stage()` dengan nama yang punya kunci `timing.stage_<nama>` di locale. Tanpa `stage()` tahapnya tidak muncul di layar progres; tanpa kunci locale yang tampil nama mentahnya.
20. **AI Manual Bawaan (ADR-014)**: Provider yang dikirim saat mulai **dan** saat Resume/Coba lagi selalu dari `effectiveProvider(caps, aiMode, provider)` (`src/lib/createFlow.ts`): provider ber-API key hanya bila `caps.apiKeys` dan `ac_ai_mode === "auto"`, selain itu `"manual_ai"`. Backend mengganti provider tersimpan dengan provider dari request, jadi mengirim provider lain di cloud berakhir `AI_KEY_MISSING`.
21. **Komponen Tambahan Terkunci SHA-256 & Lazy Startup (ADR-015)**:
   - `backend/addons.py` hanya mengunduh dari `ALLOWED_HOSTS` dengan versi, ukuran byte, dan SHA-256 terkunci di `PINNED_ADDONS` (`cuda` untuk Windows NVIDIA cuBLAS, `mediapipe` 1.2.3 + `flatbuffers` + `absl-py` + `face_landmarker.task` untuk Desktop/Web Lokal kecuali macOS Intel). Pada Cloud/Colab, `install_colab_mediapipe()` dipakai dari Langkah 3 notebook ke `<repo>/bin/mediapipe_colab` (di luar Drive); endpoint `/api/settings/addons/*/download` dan `DELETE` menolak `400` di Cloud dan `_build_status()` tidak pernah memanggil `get_app_data_dir()` saat Cloud mode aktif.
   - `backend/_lazy.py` menunda import `yt_dlp`, `cv2`, `numpy`, `openai`, dan `google.genai` sampai benar-benar dipakai (`test_startup_lazy.py` memverifikasinya di subproses bersih); modul baru yang di-import saat startup/preflight tidak boleh meng-import library berat tersebut di tingkat modul.

### F. Frontend, i18n & OS Integration (ADR-004, v1.7.0)
1. Seluruh teks antarmuka **HARUS** mendukung multi-bahasa melalui `src/locales/id.json` dan `src/locales/en.json` (menggunakan library i18n).
2. Notifikasi lewat `platform().notify()`: desktop memakai `@tauri-apps/plugin-notification`; web lokal dan cloud memakai Notification API browser bila diizinkan, selain itu toast.
3. Proses rendering video mencegah OS tidur lewat `platform().setPreventSleep()` hanya bila `platform().caps.preventSleep` (desktop).
4. Startup version check dijalankan secara non-blocking via hook `useStartupUpdateCheck` saat splash screen.
5. **Desain (spec SP2 4.6, ADR-014)**: HP dulu lalu melebar (navigasi bawah di < 768 px, sidebar ramping di atasnya), latar netral dengan satu aksen biru, mode terang dan gelap. Warna hanya lewat token di `src/index.css` (dipakai `tailwind.config.js`), tanpa warna Tailwind mentah, gradien, atau kilau. Huruf isi minimal 16 px (`text-body`), area sentuh minimal 44 × 44 px, fokus terlihat, satu tombol terisi per layar. Ikon dari `lucide-react`, hanya bila memperjelas; ikon dekoratif `aria-hidden`. Dialog memakai `src/components/ui/Dialog.tsx` (focus trap, fokus kembali, penjaga isian); jangan pakai `alert()`/`confirm()`.
6. **Lapisan Platform (ADR-013)**: Semua yang berbeda antar platform lewat `platform()` dari `src/platform/`. `@tauri-apps/*` hanya diimpor di `src/platform/desktop/` dan `__TAURI_INTERNALS__` hanya muncul di `src/platform/` (uji `src/platform/imports.test.ts`). Komponen memeriksa `platform().caps`, bukan `platform().kind`; pemeriksaan `kind` hanya untuk pilihan gerbang (`AuthGate`/`LocalGate`) di `App.tsx`.
7. **Kartu Error Buatan Frontend**: Kegagalan yang tidak bisa dilaporkan backend (link video ditolak, token web lokal hilang atau lama, server web lokal ditutup) memakai `localErrorInfo()` dari `src/lib/localErrors.ts`, teksnya di `src/locales` (`local_error.*`), dan dirender `ErrorCard`.
8. **Uji Frontend**: `npm test` (Vitest), `npm run lint` (oxlint), `npm run build` (desktop dan web lokal), `npm run build:cloud` (cloud). Teks id dan en wajib punya kunci yang sama (`src/locales/locales.test.ts`); kunci baru ditambahkan dengan `node scripts/add-locale-keys.mjs`. `src/locales/plainWords.test.ts` menolak emoji dan em dash di semua teks, serta kata teknis (transkripsi, render, encoder, JSON, token, prompt, FFmpeg, dan lainnya) di namespace layar utama (`MAIN_NAMESPACES`); namespace layar utama baru wajib ditambahkan ke daftar itu. `src/styles/contrast.test.ts` menghitung kontras WCAG AA pasangan token teks dan non-teks yang terdaftar di kedua tema; token atau pasangan baru wajib ditambahkan ke daftar itu.
9. **Kemampuan Platform SP2**: `caps.keepOpen` (`"app"` desktop, `"window"` web lokal, `"none"` cloud) memilih teks "boleh ditutup" di layar progres (`progress.keep_open_*`) dan teks banner terputus (`banner.lost_*`). `platform().saveClips(clips)` untuk **Unduh semua**: desktop meminta satu folder dan menyalin lewat `/save_file`, browser mengunduh satu per satu. `platform().pickVideo()` dipakai di langkah 1 Buat klip.
10. **Logika Layar di Fungsi Murni**: Keputusan alur Buat klip, progres, jawaban AI, pilihan yang diingat, status Riwayat, dan bagian Pengaturan ada di `src/lib/` (`createFlow.ts`, `progress.ts`, `aiAnswer.ts`, `clipChoices.ts`, `projectStatus.ts`, `settingsLayout.ts`, `routes.ts`) dan diuji Vitest. Komponen hanya menampilkan hasilnya. Rute lama dialihkan lewat `LEGACY_REDIRECTS` (`src/lib/routes.ts`); jangan menghapus alamat lama yang masih dirujuk dokumen.

### G. PyInstaller & Tauri Build Invariants (ADR-010, ADR-011)
1. **Platform Packaging Split**:
   - **Windows**: Menggunakan PyInstaller `--onefile` (`bin/backend-x86_64-pc-windows-msvc.exe`).
   - **macOS**: Menggunakan PyInstaller `--onedir` (`bin/backend-x86_64-apple-darwin/` atau `bin/backend-aarch64-apple-darwin/`) yang dikonfigurasi via `src-tauri/tauri.macos.conf.json`.
2. Script build: jalankan `build-be.ps1` atau `build-be.bat` untuk Windows (selalu gunakan flag `--clean`), atau `build-mac-local.sh` untuk environment macOS.
3. Release manual macOS Intel x86_64 dengan bundel updater artifact dijalankan menggunakan `release-mac-intel.sh` (panduan di `docs/release-macos-intel.md`).
4. Konfigurasi perizinan Tauri ada di `src-tauri/tauri.conf.json` dan `src-tauri/capabilities/default.json`.
5. **NSIS Preinstall File-Lock Prevention (`hooks.nsh`)**: Installer Windows wajib mengeksekusi `taskkill` untuk semua kemungkinan proses backend dan aplikasi (`backend.exe`, `backend-x86_64-pc-windows-msvc.exe`, `Auto Clipper.exe`, `app.exe`) sebelum instalasi dimulai guna menghindari `WinError 32` file lock.
6. **PyInstaller Dependency Collection**: Konfigurasi `backend.spec` wajib mendaftarkan `backend.metadata` pada `hiddenimports` dan mengumpulkan paket runtime penting seperti `numpy` via `collect_all('numpy')`.
7. **Tauri Dev Build Zombie Lock (Windows)**: Jika *build* Tauri gagal dengan pesan `PermissionDenied (os error 5)` atau panic pada `tauri-build` saat menjalankan `npm run tauri dev` atau `cargo run`, itu menandakan adanya *zombie sidecar process* (`backend.exe` atau `Auto Clipper.exe`) yang mengunci folder `target/debug`. Solusi wajib: Jalankan `taskkill /F /IM "backend.exe" /T` dan `taskkill /F /IM "Auto Clipper.exe" /T`, kemudian bersihkan *cache* yang *corrupt* dengan perintah `cargo clean` di dalam direktori `src-tauri` sebelum me-rebuild.
8. **Paket Web Lokal (ADR-013)**: `.github/workflows/web-package.yml` membangun `Auto-Clipper-Web-<windows|macos-arm64|macos-x64|linux>.zip` dari `backend.spec` yang sama, `ffmpeg-static@5`, dan build UI (`npm run build -- --outDir web-ui`, karena PyInstaller menulis ke `dist/`). Susunan paket diatur `scripts/assemble_web_package.py` dan diuji `scripts/smoke_web_package.py` di CI. Skrip `.sh`/`.command` wajib berakhiran baris LF (`.gitattributes`).

### H. Dokumentasi ADR & Testing
1. Setiap perubahan arsitektur signifikan, penambahan library inti, atau perubahan alur data wajib dibuatkan dokumen ADR di `docs/decisions/` format `[nomor]-[nama-singkat].md`.
2. Selalu jalankan unit test backend dengan `pytest` di folder `backend/tests/`, `npm test` dan `npm run lint`, serta validasi build frontend (`npm run build` dan `npm run build:cloud`) sebelum menyelesaikan task besar.

### I. Developer Mode & Uvicorn Auto-Reload
1. Saat menjalankan backend secara lokal untuk *development*, gunakan environment variable `AUTO_CLIPPER_DEV_TOKEN="dev-token"` dan jalankan `uvicorn` dengan mode auto-reload. Frontend akan menggunakan token statis ini untuk handshake (mem-bypass pembacaan `stdout` untuk `PORT`/`TOKEN`).

## 3. Direktori & File Penting
- `backend/main.py`: Entry point FastAPI, exception handler, port/token emitter.
- `backend/_lazy.py`: Proxy `LazyModule` / `LazyAttr` agar library berat tidak dimuat saat startup (`test_startup_lazy.py`).
- `backend/addons.py`: Pengunduh & aktivator komponen opsional terkunci SHA-256 (`cuda`, `mediapipe`) serta `install_colab_mediapipe()`.
- `backend/jobs.py`: Worker queue, pipeline eksekusi klip, resume/retry logic.
- `backend/ai_utils.py`: Integrasi Whisper, model registry, prompt LLM & JSON sanitizer.
- `backend/crop_utils.py`: Face tracking (OpenCV), generator kanvas background (`build_canvas_background_filter`), subtitle ASS anti-overlap & typography parser.
- `backend/logger.py`: Fail-safe error logger (`backend_error.log`).
- `backend/db.py`: SQLite database schema & repository functions, snapshot `history.db` ke pustaka dan pemulihan saat startup.
- `backend/workspace.py`: Pemisahan work dir vs pustaka, `publish` atomik, `uploads_dir`, ruang disk.
- `backend/errors.py`: `AppError`, katalog `ERROR_CODES` (id/en), `classify_download_error`, `to_app_error`.
- `backend/job_queue.py`: Antrean FIFO job berat (`AUTO_CLIPPER_MAX_HEAVY_JOBS`).
- `backend/preflight.py`: Pengecekan awal (`run_preflight`, `blocking_error`) di balik `GET /api/preflight`.
- `backend/drive_mount.py`: Aturan Drive Colab yang belum ter-mount (`refuse_unmounted`, `library_unavailable`, `local_dir`).
- `backend/stage_timer.py`: Waktu dan RAM puncak per tahap ke `metadata["timings"]`; tumpukan tahap hidup, `report()`, dan `current_stage()` untuk `current` di status job.
- `backend/cookies.py`: Validasi, penyimpanan, status, dan salinan kerja `cookies.txt` untuk yt-dlp.
- `backend/path_guard.py`: Daftar tolak file privat (cookies, `history.db*`, log) untuk endpoint yang menerima path, dan pembersih nama file unggahan.
- `backend/video_utils.py`: Unduhan yt-dlp (urutan client, cookies, Deno/EJS, format), ekstraksi audio.
- `backend/colab_api.py`: Entry point Colab/cloud (`--workspace`, `--work-dir`, tunnel Cloudflare, GPU keep-alive).
- `scripts/colab_preflight.py`: Mencetak hasil preflight dalam bahasa Indonesia di notebook Colab sebelum server menyala.
- `scripts/benchmark_pipeline.py`: Menjalankan satu video lewat pipeline asli dan mencetak tabel waktu/RAM per tahap.
- `backend/tests/test_subtitle_render.py` & `backend/tests/test_jobs_subtitle.py`: Pengujian render subtitle ASS, anti-overlap, dan jobs threading.
- `Auto_Clipper_Colab.ipynb`: Jupyter Notebook untuk menjalankan backend FastAPI di Google Colab dengan GPU gratis dan Ngrok/Cloudflare. Memasang FFmpeg (paket Ubuntu, tanpa jaminan NVENC), cloudflared, dan Deno (`DENO_INSTALL=/usr/local`, gagal pasang tidak menghentikan notebook), mengatur `AUTO_CLIPPER_WORKSPACE` (Drive) dan `AUTO_CLIPPER_WORK_DIR=/content/work`, lalu menjalankan `scripts/colab_preflight.py` sebelum server. Sel diidentifikasi lewat `metadata.id` dan diuji di `backend/tests/test_colab_api.py`; edit dengan alat yang mempertahankan format JSON (indent 1, urutan kunci) dan pertahankan urutan sel.
- `src/App.tsx`: Routing, splash screen, startup update check, pilihan gerbang per platform (`AuthGate`/`LocalGate`).
- `src/pages/CreatePage.tsx`: Layar Buat klip empat langkah; komponennya di `src/components/create/` (`StepIndicator`, `VideoStep`, `ClipOptions`, `PreflightNotices`, `ProgressPanel`, `MomentStep`).
