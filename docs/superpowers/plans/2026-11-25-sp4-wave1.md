# SP4 Wave 1: App Identity, AI Re-pick Without an API Key, Local Web Update Notice, and Deferred Minors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show who made Auto Clipper and which version runs on every platform (footer, "Tentang Auto Clipper", splash), let people without an API key pick moments again from an old project (`POST /jobs/{id}/rerun-manual`), tell Auto Clipper Web users that a new version exists (`GET /api/update-check`), and close the SP2/SP3 deferred minors that are still valid.

**Architecture:** One identity module (`src/lib/appInfo.ts`, version from Vite `define`) feeds the footer, the About card, the splash and the cloud gate. The splash gets a new cap (`caps.splash`) so the web shows it once per tab until the first `/health` answer (0.8 s to 2.5 s) while desktop keeps its current timing. The backend builds a re-pick project synchronously: it reuses the old transcript, builds the manual AI prompt with the same `generate_manual_prompt`, and saves a new history row as `AWAITING_MANUAL`; the existing `resume-manual` makes the clips. A stdlib-only `backend/update_check.py` asks GitHub once a day (web mode only) and only passes on links under this repo's releases. Pure functions in `src/lib/` (`splash.ts`, `repick.ts`, `updateNotice.ts`) hold every screen decision.

**Tech Stack:** React 19, TypeScript 6, Vite 8, Tailwind 3, i18next, Vitest 5 + jsdom, oxlint; Python 3.11+, FastAPI, pydantic v2, pytest, stdlib `urllib.request`.

**Spec:** `docs/superpowers/specs/2026-11-25-sp4-wave1-design.md` (binding; sections 4.1 to 4.7, task order in section 7). Parent: `docs/superpowers/specs/2026-11-12-enhancement-roadmap.md` (section 6). Earlier ledgers: `tasks/sp2-ledger.md`, `tasks/sp3-ledger.md`. ## Spec ambiguities resolved (rulings for every task)

1. **Version source.** `vite.config.ts` gets `define: { __APP_VERSION__: JSON.stringify(<package.json version>) }`; `appVersion()` returns it. The older `APP_VERSION` in `src/lib/settingsLayout.ts` (a direct `package.json` import) is removed so there is one source. A test keeps `src-tauri/tauri.conf.json` and `src-tauri/Cargo.toml` equal to `package.json`.
2. **Splash per platform without a `kind` check.** New cap `caps.splash: "startup" | "tab"` (desktop `"startup"`: unchanged, shown while saved settings and the sidecar load; local and cloud `"tab"`: once per tab). F.6 forbids `kind` checks outside the gate choice.
3. **"Cek sambungan pertama" on the web** = one `GET {API_URL}/health` sent as soon as saved settings are loaded (that is when `platform().backend()` has set `API_URL`). The splash closes when it answers (success or failure) but not before 0.8 s, and at 2.5 s at the latest. A reload in the same tab shows no splash (a plain background while settings load, usually a few milliseconds).
4. **Re-pick when the source video is gone (Colab).** The transcript must exist (it lives in the library on Drive); without it the request is refused with `RERUN_SOURCE_MISSING`. A missing source video is refused only when it cannot come back: no work dir (desktop, local web), or an uploaded file that is gone. With a work dir (Colab) and a link project the request is accepted and `resume-manual` downloads only the video again at the paste step (`_restore_source_video`, E.9); nothing is transcribed again. Spec 4.4 "menolak bila sumber tidak ada lagi (mis. sesi Colab habis)" read together with the wave goal "termasuk HP lewat Colab": refusing every old Colab project would make the feature useless on the phone.
5. **`rerun_ai` also gets a new title.** Today `create_rerun_ai_job` keeps the old title, so it writes into the same project folder and the clip files `<title>_clip_<n>.mp4` overwrite the old clips. Owner decision (spec 3, "Hasil AI ulang"): a new project, old clips intact, "sama dengan AI ulang versi API key". Both re-picks use `repick_title()`: `"<old> (pilihan ulang)"`, then `"(pilihan ulang 2)"` and so on.
6. **`resume_manual_job` timings.** The running job starts with `timings: []` (spec 4.6, no stale tracker facts on the progress screen). The earlier prepare rows (download, extract_audio, transcribe, ai_analysis) are kept as `job["earlier_timings"]` and put back in front when the job finishes, so Detail waktu still shows them. Rows of the make stages (tracking, render, hook_concat, publish) from earlier runs are dropped.
7. **The backend does not know its own version.** The app sends `current=<appVersion()>` to `GET /api/update-check`; the backend validates it as `X.Y.Z` (400 otherwise) and echoes it. No second version constant in Python.
8. **Update-check failures are not cached**: each app start (and "Coba lagi") asks again; only a successful answer is cached for 24 h.
9. **"Pilih ulang momen".** One menu item (Riwayat list and project page) for projects with status `DONE` and a stored `metadata.subtitle_path`, on all platforms. One dialog; the route comes from `effectiveProvider(caps, aiMode, provider)` (E.20): `manual_ai` uses `rerun-manual`, anything else uses `rerun_ai`. It replaces "Pilih ulang momen dengan AI" and `AiCorrectDialog`.
10. **Action for `RERUN_SOURCE_MISSING`:** a new `_ACTIONS` entry `new_project` ("Buat proyek baru" / "Start a new project"): clears the Buat klip screen and goes to `/`.
11. **`AuthGate` links** stay `<a target="_blank" rel="noopener noreferrer">`: the gate only runs in a browser (cloud), where that is what `openExternal` does; the hrefs come from `SOCIAL_LINKS`.
12. **"©" and the emoji check.** U+00A9 matches `\p{Extended_Pictographic}`. The copyright line is built in code (`copyrightLine()`), never in a locale file, and `src/pages/SettingsPage.real.test.tsx` excludes U+00A9 from its emoji regex.
13. **`/rerun-ai` (hyphen)** no longer appears anywhere in `src/` (checked 2026-11-25); Task 4 adds a test that keeps it that way.
14. **Task order** is the spec's section 7 order. Nothing in the code forces a change.

```ts
// When the splash closes (SP4 spec 4.3). No React here.

export const SPLASH_MIN_MS = 800;
export const SPLASH_MAX_MS = 2500;
/** sessionStorage key: the web splash shows once per tab. */
export const SPLASH_SEEN_KEY = "ac_splash_seen";

export function splashSeen(storage: Pick<Storage, "getItem"> | null): boolean {
  try {
    return storage?.getItem(SPLASH_SEEN_KEY) === "1";
  } catch {
    return false; // unreadable (private mode, blocked): show it once more
  }
}

export function markSplashSeen(storage: Pick<Storage, "setItem"> | null): void {
  try {
    storage?.setItem(SPLASH_SEEN_KEY, "1");
  } catch {
    // Not writable: the splash shows once per page load instead.
  }
}

/** How long the splash still stays: until 0.8 s once the connection check answered, else until 2.5 s. */
export function msUntilSplashCloses(elapsedMs: number, checked: boolean): number {
  return Math.max(0, (checked ? SPLASH_MIN_MS : SPLASH_MAX_MS) - elapsedMs);
}

/** Desktop ("startup") shows it while settings load, as before; the web ("tab") follows useWebSplash. */
export function splashVisible(mode: "startup" | "tab", isInitializing: boolean, webSplashShowing: boolean): boolean {
  return mode === "startup" ? isInitializing : webSplashShowing;
}
```

```ts
import { useEffect, useState } from "react";
import axios from "axios";
import { API_URL } from "../platform/backendUrl";
import { SPLASH_MAX_MS, markSplashSeen, msUntilSplashCloses, splashSeen } from "../lib/splash";

function tabStorage(): Storage | null {
  try {
    return window.sessionStorage;
  } catch {
    return null;
  }
}

/**
 * The web splash (SP4 spec 4.3): once per tab, from the first load until the first connection
 * check answers (either way), at least 0.8 s and at most 2.5 s. `ready`: saved settings are
 * loaded, so `platform().backend()` has set API_URL and the check can go out.
 * Returns whether the splash shows now.
 */
export function useWebSplash(enabled: boolean, ready: boolean): boolean {
  const [show] = useState(() => enabled && !splashSeen(tabStorage()));
  const [startedAt] = useState(() => Date.now());
  const [checked, setChecked] = useState(false);
  const [done, setDone] = useState(false);

  useEffect(() => {
    if (show) markSplashSeen(tabStorage());
  }, [show]);

  useEffect(() => {
    if (!show || !ready) return;
    let alive = true;
    axios
      .get(`${API_URL}/health`, { timeout: SPLASH_MAX_MS })
      .catch(() => undefined)
      .finally(() => {
        if (alive) setChecked(true);
      });
    return () => {
      alive = false;
    };
  }, [show, ready]);

  useEffect(() => {
    if (!show || done) return;
    const timer = setTimeout(() => setDone(true), msUntilSplashCloses(Date.now() - startedAt, checked));
    return () => clearTimeout(timer);
  }, [show, done, checked, startedAt]);

  return show && !done;
}
```

```python
def _title_in_use(title: str) -> bool:

def repick_title(old_title: str) -> str:
    """A free name for moments picked again: its own project folder, so the old clips stay (SP4 spec 3).

    "Talk" -> "Talk (pilihan ulang)", then "Talk (pilihan ulang 2)", ... A re-pick of a re-pick
    does not stack the suffix.
    """
    base = _REPICK_SUFFIX_RE.sub("", (old_title or "").strip()) or "Proyek"
    title = f"{base} ({REPICK_SUFFIX})"
    n = 2
    while _title_in_use(title):
        title = f"{base} ({REPICK_SUFFIX} {n})"
        n += 1
    return title
```

```python
def _read_transcript(subtitle_path: str) -> tuple:
    """The transcript as SRT text for the AI prompt, and the video length it covers in seconds."""
    import json
    from backend.ai_utils import build_srt_from_segments
    with open(subtitle_path, "r", encoding="utf-8") as f:
        raw = f.read()
    if subtitle_path.endswith(".json"):
        segments = [
            {"start": s.get("start"), "end": s.get("end"), "text": s.get("text")}
            for s in json.loads(raw).get("segments", [])
        ]
        duration = max((float(s["end"] or 0) for s in segments), default=0.0)
```

```ts
import type { Caps } from "../platform/types";
import { MANUAL_PROVIDER, effectiveProvider, type AiMode } from "./createFlow";
import { projectStatusKey } from "./projectStatus";

// "Pilih ulang momen" (SP4 spec 4.4). No React here.

/** Same limit as REPICK_EXTRA_MAX in backend/main.py. */
export const REPICK_EXTRA_MAX = 500;
/** Same upper bound as RerunManualRequest.max_clips in backend/main.py. */
export const REPICK_MAX_CLIPS = 50;

export type RepickMode = "manual" | "api";

interface RepickJobLike {
  status?: string | null;
  metadata?: { subtitle_path?: unknown } | null;
}

/** Finished projects that kept their spoken text (the backend reads it again, nothing is transcribed again). */
export function canRepick(job: RepickJobLike | null | undefined): boolean {
  if (!job || projectStatusKey(job) !== "done") return false;
  const path = job.metadata?.subtitle_path;
  return typeof path === "string" && path.trim() !== "";
}

/** The same provider rule as every start and resume (E.20): manual AI means rerun-manual. */
export function repickMode(caps: Pick<Caps, "apiKeys">, aiMode: AiMode, provider: string): RepickMode {
  return effectiveProvider(caps, aiMode, provider) === MANUAL_PROVIDER ? "manual" : "api";
}

/** The optional clip count: empty, zero or not a number means "choose automatically" (0). */
export function parseClipCount(text: string): number {
  const n = Number.parseInt(text.trim(), 10);
  return Number.isFinite(n) && n > 0 ? Math.min(n, REPICK_MAX_CLIPS) : 0;
}
```

```python
"""Tells Auto Clipper Web that a newer version is out (SP4 spec 4.5, ADR-016). Stage 1: notice only.

Asks GitHub for the latest release at most once a day (cached in app data), with a generic
User-Agent and nothing about the user or this computer in the request. Only links inside this
repository's releases are passed on. Nothing is downloaded or installed here. Standard library
only, and imported only when the endpoint runs (E.21).
"""
import json
import os
import platform
import re
import sys
import time
import urllib.error
import urllib.request
from typing import Optional

from backend.logger import log_app, log_error

LATEST_RELEASE_API = "https://api.github.com/repos/DhimasPH/auto-clipper/releases/latest"
RELEASES_PREFIX = "https://github.com/DhimasPH/auto-clipper/releases/"
USER_AGENT = "AutoClipper-UpdateCheck"
CACHE_FILE_NAME = "update_check.json"
CACHE_SECONDS = 24 * 60 * 60
TIMEOUT_SECONDS = 5
MAX_ANSWER_BYTES = 1_000_000
# The zips .github/workflows/web-package.yml builds: Auto-Clipper-Web-<target>.zip
TARGETS = ("windows", "macos-arm64", "macos-x64", "linux")
TAG_PREFIX = "app-v"
_VERSION = re.compile(r"(\d{1,4})\.(\d{1,4})\.(\d{1,4})", re.ASCII)


def parse_version(text) -> Optional[tuple]:
    """(major, minor, patch) for "1.19.0"; None for anything else."""
    if not isinstance(text, str):
        return None
    match = _VERSION.fullmatch(text.strip())
    return tuple(int(part) for part in match.groups()) if match else None


def package_target(sys_platform: Optional[str] = None, machine: Optional[str] = None) -> Optional[str]:
    """The web package name for the system this backend runs on."""
    sys_platform = sys_platform or sys.platform
    machine = (machine or platform.machine() or "").lower()
    if sys_platform.startswith("win"):
        return "windows"
    if sys_platform == "darwin":
        return "macos-arm64" if machine in ("arm64", "aarch64") else "macos-x64"
    if sys_platform.startswith("linux"):
        return "linux"
    return None


def _trusted(url) -> Optional[str]:
    return url if isinstance(url, str) and url.startswith(RELEASES_PREFIX) else None


def summarize(release: dict, target: Optional[str]) -> dict:
    """{latest, download_url, release_url} from a GitHub release answer. ValueError when it is not ours."""
    tag = release.get("tag_name") if isinstance(release, dict) else None
    latest = tag[len(TAG_PREFIX):] if isinstance(tag, str) and tag.startswith(TAG_PREFIX) else None
    if parse_version(latest) is None:
        raise ValueError(f"unexpected release tag {tag!r}")
    wanted = f"Auto-Clipper-Web-{target}.zip" if target else None
    download_url = None
    for asset in release.get("assets") or []:
        if wanted and isinstance(asset, dict) and asset.get("name") == wanted:
            download_url = _trusted(asset.get("browser_download_url"))
            break
    return {"latest": latest, "download_url": download_url, "release_url": _trusted(release.get("html_url"))}


def fetch_latest_release() -> dict:
    """One GET to GitHub: generic User-Agent, no query string, no user data."""
    request = urllib.request.Request(
        LATEST_RELEASE_API,
        headers={"User-Agent": USER_AGENT, "Accept": "application/vnd.github+json"},
    )
    with urllib.request.urlopen(request, timeout=TIMEOUT_SECONDS) as response:
        return json.loads(response.read(MAX_ANSWER_BYTES).decode("utf-8"))


def _read_cache(path: str) -> Optional[dict]:
    try:
        with open(path, "r", encoding="utf-8") as f:
            data = json.load(f)
        return data if isinstance(data, dict) else None
    except (OSError, ValueError):
        return None


def _write_cache(path: str, data: dict) -> None:
    try:
        os.makedirs(os.path.dirname(path), exist_ok=True)
        tmp = f"{path}.part"
        with open(tmp, "w", encoding="utf-8") as f:
            json.dump(data, f)
        os.replace(tmp, path)
    except OSError as e:
        log_error("update_check.cache", e)


def _failure_kind(exc: BaseException) -> str:
    if isinstance(exc, urllib.error.HTTPError):
        return "rate_limited" if exc.code in (403, 429) else "bad_answer"
    if isinstance(exc, (urllib.error.URLError, OSError)):
        return "offline"
    return "bad_answer"


def check(current: str, *, force: bool = False, cache_path: str, now: Optional[float] = None,
          target: Optional[str] = None) -> dict:
    """Whether a version newer than ``current`` is out. Never raises: a failure is ``error``, not cached."""
    now = time.time() if now is None else now
    target = target or package_target()
    cached = None if force else _read_cache(cache_path)
    fresh = (
        cached is not None
        and cached.get("target") == target
        and isinstance(cached.get("checked_at"), (int, float))
        and 0 <= now - cached["checked_at"] < CACHE_SECONDS
        and parse_version(cached.get("latest")) is not None
    )
    if fresh:
        info = {key: cached.get(key) for key in ("latest", "download_url", "release_url")}
        checked_at = cached["checked_at"]
    else:
        try:
            info = summarize(fetch_latest_release(), target)
        except Exception as exc:
            kind = _failure_kind(exc)
            log_app(f"Pemeriksaan versi baru gagal ({kind}): {type(exc).__name__}")
            return {"current": current, "latest": None, "update_available": False, "download_url": None,
                    "release_url": None, "checked_at": now, "error": kind}
        checked_at = now
        _write_cache(cache_path, {**info, "target": target, "checked_at": now})
    latest = info.get("latest")
    newer = parse_version(latest) is not None and parse_version(latest) > parse_version(current)
    return {
        "current": current,
        "latest": latest,
        "update_available": newer,
        # Checked again: a cache file is only a file on disk.
        "download_url": _trusted(info.get("download_url")),
        "release_url": _trusted(info.get("release_url")),
        "checked_at": checked_at,
    }
```

```python
@app.get("/api/update-check")
def api_update_check(current: str = "", force: int = 0):
    """Auto Clipper Web only (SP4 spec 4.5): is a newer version out? A quiet answer, never an error card."""
    if not web_ui.is_web_mode():
        return JSONResponse(status_code=404, content={"status": "error", "message": "Not available in this app"})

    return update_check.check(current, force=bool(force), cache_path=cache_path)
```

```ts
import { RELEASES_URL_PREFIX } from "./appInfo";

// Auto Clipper Web's update notice (SP4 spec 4.5): GET /api/update-check and what Bantuan shows. No React here.

export interface UpdateCheck {
  latest: string | null;
  updateAvailable: boolean;
  /** The zip for this system, else the release page; only links inside the repository's releases. */
  link: string | null;
  /** The server could not ask GitHub (offline, rate limit, odd answer). */
  failed: boolean;
}

const trusted = (value: unknown): string | null =>
  typeof value === "string" && value.startsWith(RELEASES_URL_PREFIX) ? value : null;

export function asUpdateCheck(data: unknown): UpdateCheck | null {
  if (!data || typeof data !== "object" || Array.isArray(data)) return null;
  const d = data as Record<string, unknown>;
  return {
    latest: typeof d.latest === "string" ? d.latest : null,
    updateAvailable: d.update_available === true,
    link: trusted(d.download_url) ?? trusted(d.release_url),
    failed: typeof d.error === "string" && d.error !== "",
  };
}

export type UpdatePhase = "idle" | "checking" | "done";
export type UpdateNoticeView = "checking" | "available" | "latest" | "failed";

export function updateNoticeView(phase: UpdatePhase, result: UpdateCheck | null): UpdateNoticeView {
  if (phase !== "done") return "checking";
  if (!result || result.failed) return "failed";
  if (result.updateAvailable) return result.latest && result.link ? "available" : "failed";
  return "latest";
}
```

`src/hooks/useUpdateNotice.ts`:

```ts
import { useCallback, useEffect, useRef, useState } from "react";
import axios from "axios";
import { appVersion } from "../lib/appInfo";
import { asUpdateCheck, updateNoticeView, type UpdateCheck, type UpdateNoticeView, type UpdatePhase } from "../lib/updateNotice";
import { API_URL } from "../platform/backendUrl";

export interface UpdateNotice {
  view: UpdateNoticeView;
  latest: string | null;
  link: string | null;
  /** "Coba lagi" / "Periksa pembaruan": asks GitHub again, past the server's 24 h cache. */
  recheck: () => Promise<void>;
}

/** Checks once when the app opens (the server caches the answer for 24 h). No pop-up: Bantuan shows the result. */
export function useUpdateNotice(enabled: boolean): UpdateNotice {
  const [phase, setPhase] = useState<UpdatePhase>("idle");
  const [result, setResult] = useState<UpdateCheck | null>(null);
  const started = useRef(false);

  const run = useCallback(async (force: boolean) => {
    setPhase("checking");
    try {
      const res = await axios.get(`${API_URL}/api/update-check`, {
        params: { current: appVersion(), force: force ? 1 : 0 },
        timeout: 15000,
      });
      setResult(asUpdateCheck(res.data));
    } catch (err) {
      console.warn("Update check unavailable:", err);
      setResult(null);
    } finally {
      setPhase("done");
    }
  }, []);

  useEffect(() => {
    if (!enabled || started.current) return;
    started.current = true;
    void run(false);
  }, [enabled, run]);

  return {
    view: updateNoticeView(phase, result),
    latest: result?.latest ?? null,
    link: result?.link ?? null,
    recheck: () => run(true),
  };
}
```

```markdown
# ADR-016: Identitas Aplikasi Satu Sumber, Pilih Ulang Momen Tanpa API Key, dan Pemberitahuan Versi Baru Auto Clipper Web

Tanggal: 2026-11-25 · Status: Diterima · Spec: `docs/superpowers/specs/2026-11-25-sp4-wave1-design.md` · Rencana: `docs/superpowers/plans/2026-11-25-sp4-wave1.md`

## 1. Konteks

Aplikasi tidak menunjukkan pembuat, versi, dan tautan komunitas secara konsisten; splash di web langsung hilang. "Pilih ulang momen" hanya jalan dengan API key (`POST /jobs/{id}/rerun_ai`), padahal jalur bawaan sejak SP2 adalah AI manual. Pengguna Auto Clipper Web (paket web lokal) tidak tahu ada versi baru karena updater hanya ada di desktop.

## 2. Keputusan

### A. Satu sumber identitas (`src/lib/appInfo.ts`)
Nama, pemegang hak cipta, versi (`__APP_VERSION__` dari `package.json` lewat Vite `define`), delapan tautan, dan awalan URL rilis hanya ada di file ini. `appInfo.test.ts` menolak salinan URL di file lain di `src/` dan menjaga versi `src-tauri/tauri.conf.json` dan `Cargo.toml` sama dengan `package.json`. Tahun hak cipta dihitung saat halaman tampil.

### B. Splash per kemampuan platform (`caps.splash`)
`"startup"` (desktop): tampil selama pengaturan dan sidecar dimuat, seperti sebelumnya. `"tab"` (web lokal dan cloud): sekali per tab (`sessionStorage`), sampai `GET /health` pertama menjawab, minimal 0,8 detik, maksimal 2,5 detik. Pilihan lewat cap, bukan `platform().kind` (ADR-013).

### C. `POST /jobs/{id}/rerun-manual`
Sinkron, tanpa thread: membaca teks ucapan proyek lama, menyusun perintah dengan `generate_manual_prompt` (fungsi yang sama dengan alur manual), menyimpan proyek baru `AWAITING_MANUAL` (`history_ref`, `timings: []`, judul "(pilihan ulang)" yang unik), lalu jawaban yang ditempel lewat `resume-manual` seperti biasa. Validasi sama dengan `rerun_ai` (`_canvas_image_refused`, `_resolve_safe_output_dir`, `path_guard`). Teks ucapan wajib masih ada; video sumber boleh hilang hanya bila bisa dikembalikan (`_restore_source_video` di work dir Colab).
```
